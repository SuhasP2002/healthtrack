# 💚 HealthTrack — Habit Tracking App

> A full-stack habit tracking application with analytics, reminders, weekly email reports, and PDF export.

![Tech Stack](https://img.shields.io/badge/React-18-blue?logo=react)
![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.2-green?logo=springboot)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-15-blue?logo=postgresql)
![Docker](https://img.shields.io/badge/Docker-Compose-2496ED?logo=docker)

## ✨ Features
- 🔐 JWT Authentication — Register, login, forgot/reset password
- ✅ Habit Management — Create, update, delete and log daily habits
- 📊 Analytics Dashboard — Visual charts showing weekly completion trends
- 🔔 In-App Reminders — Set custom daily reminder times with toast notifications
- 📧 Weekly Email Reports — Auto-sent every Monday with last week's habit summary
- 📄 PDF Export — Download a 30-day habit report as a formatted PDF
- 🌙 Dark / Light Mode — Theme toggle

## 🛠️ Tech Stack
- **Frontend**: React 18, React Router, Axios, Chart.js
- **Backend**: Spring Boot 3.2, Spring Security, JWT, Spring Data JPA
- **Database**: PostgreSQL 15
- **Infrastructure**: Docker, Docker Compose, Nginx

## 🚀 Getting Started

### Prerequisites
- Docker Desktop installed and running

### Run the app
```bash
git clone https://github.com/SuhasP2002/healthtrack.git
cd healthtrack
docker-compose up --build
```

Open **http://localhost:3000**
